# のぼれ！タイピングアスレチック

小学生向けのスマホ用タイピング練習アプリです。表示されたことばを入力すると、キャラクターがアスレチック（はしご・ネット・ロープ・ボルダリング・のぼりぼう）を1だんずつのぼっていきます。10だん（30m）のぼるとゴールです。

## できること

- コースは4つ：ひらがな（かんたん）／てんてん・カタカナ／小さい字・長いことば／ABC えいご
- フリック入力でも、ローマ字入力でも遊べます（`si`/`shi`、`tu`/`tsu` などどちらの書き方でもOK）
- 合っている文字は緑色になり、正しく入力し終わると自動でのぼります（決定ボタンは不要）
- ローマ字のヒント表示、パス、効果音のオン・オフ
- リズムモード（ゆっくり／ふつう／はやい）：ことばの文字が1はくに1文字ずつ右から流れてきます。文字が左の輪に来たときに入力するとパーフェクト、ずれるとグッド、間に合わないとそのことばはミスになります
- コースごとのベストタイムを記録（使っている端末のブラウザの中にだけ保存）

## 使い方

`index.html` をブラウザで開くだけで使えます。

## ことばの追加方法

`index.html` の `COURSES` の中の `words` に、`絵文字 ことば` を `|` で区切って書き足します。
